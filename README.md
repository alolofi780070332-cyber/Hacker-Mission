# HACKER MISSION
### A Smart Bank Cybersecurity Challenge

## About the Game
Hacker Mission is a simple text-based game made using C++. The player solves four secret code challenges to complete the mission and get a maximum score of 100 points.

## Game Levels
- Level 1: Login System — Caesar Cipher.
- Level 2: Firewall Bypass — Binary to ASCII.
- Level 3: Data Encryption — Reverse Cipher.
- Level 4: Digital Vault — Combined Cipher.

## Features
- Main Menu
- Player Name
- Four Levels
- Score System (100 Points)
- Three Attempts for Each Level

## Requirements
- C++ Compiler
- Visual Studio

## How to Run
1. Download the project.
2. Open HackerMission.cpp in Visual Studio.
3. Compile the code.
4. Run the program.
5. Start the mission and solve the challenges.

## Scoring System
- Level 1: 10 Points
- Level 2: 20 Points
- Level 3: 30 Points
- Level 4: 40 Points

**Total Score: 100 Points**
